Elo form playground

Write an Elo type schema. The form is generated from it, and every check is run by Elo itself.

Schema

Options

the second argument of eloForm, as JSON

Labels are taken from labels here when it names the field (by key, or by path such as .lines.*.qty), and from the schema otherwise. units puts a unit beside a field, named the same way or by type ("Percent": "%"). title and messages are here too.

Form

options set in the options attribute · type read from the schema messages built-in text
