5. HTML first, then taken over

Mode 4 is the floor; this is the same page for a browser that runs scripts. The HTML arrives and works. When the script arrives it builds the live form from the same plan and options, keeps whatever was typed in the meantime, and takes the place of the HTML. From then on it is mode 2 — or mode 3, if it is handed checks. Turn JavaScript off and reload: the page still works, as mode 4.

What to copy

  • The page's script: 5-hydrate.js.
  • From the server: everything of mode 4, plus what the form holds as a JSON block in the page, for the script to start from.
  • This page without checks (it becomes mode 2) and with checks (mode 3). The server decides which, per schema.

Security profile: that of the mode it becomes

  • Without checks it is mode 2: nothing of the schema runs in the browser. With checks it is mode 3.
  • The two can be decided per schema: checks for the ones you wrote, none for the ones you did not. The page is the same.
  • The plan and the options must be the ones the HTML was written with; nothing checks that for you.
