4. HTML only

The server writes the form as HTML. Each plain field carries a name, so the <form> below posts with no script at all: this page has none, and its policy allows none. Sending it is a GET to this same address; the server reads the fields back the way the form itself would, checks them, and answers with the form again, the problem written on its field.

What to copy

  • From the server: htmlForm(), which is renderHtml to write and readPosted to read back, with the same options both times.
  • From the page: a <form method="get"> around what the server wrote, and a button. View this page's source.

Security profile: nothing runs in the browser at all

  • The page forbids every script, its own included.
  • As in mode 2, the schema reaches the reader only as text, and runs only on your server.
  • Field names come from the schema. Inside a form that also posts things of yours — a token, a hidden id — a schema with an attribute of the same name would post under it. Give names a function that prefixes them.
  • What it cannot do: lists, choices between alternatives, durations and JSON files need a script to be filled in. Their buttons are there and do nothing.
