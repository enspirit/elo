1. All in the page

The page carries Elo. It fetches the schema as text, reads it, builds the form, and compiles each check with new Function the first time it is needed. The server does nothing but hand the schema over.

What to copy

  • The page's script: 1-in-page.js, ten lines.
  • From the server: nothing but serving the schema. And a policy with 'unsafe-eval'.

Security profile: only for schemas you wrote

  • The policy has to allow 'unsafe-eval'. That is not only about this form: it takes a protection away from the whole page, for any other script that ends up in it.
  • Elo's compiler runs on the schema in the reader's browser, and so does what it compiles. What that code can reach is Elo's sandbox, and nothing else stands between a schema and the page.
  • A schema can take time: checks run on the main thread at every keystroke, and nothing bounds them.
  • Under a policy without 'unsafe-eval' the form still builds, and says that nothing is checked.
